# 规划与进度

这份文档记的是**决定和理由**，不是功能清单 —— 代码里能看到的东西不往这写。
改了方向就更新它，别让它变成考古材料。

## 产品定位（决定了后面所有取舍）

**自托管的单人加密永续分析工具**，面向个人交易者，开源。

三条由此推出的硬约束：

1. **不做多租户。** 一个部署对应一个主人，`auth` 表上的 `CHECK (id = 1)` 把这条
   写进了 schema。多租户意味着要处理越权、会话劫持、用户枚举、密码重置链路，
   每一样都是凭据泄露的新入口 —— 而这个程序手里握着交易所 API key。
   对这类工具来说多租户不是加分项，是减分项。
2. **一个人可以有多个账户。** 所以数据有 `account_id` 维度，没有 `user_id`。
3. **只读。** `account.py` 不实现任何下单/撤单/改杠杆接口，且这条约束由
   `test_readonly_boundary.py` 机械校验，不是靠注释承诺。

标的范围不只是加密：币安在架的 762 个永续里有 **191 个是股票/商品/指数**
（`TRADIFI_PERPETUAL`），占四分之一。做资讯关联、板块分类时别只盯着 crypto。

## 待定：需要你先做决定

### 层 4：第二家交易所

**卡在"是哪家"上。** 只有一个实现的适配器接口，十有八九是错的 —— 等确定了第二家，
照着它真实的 API 形状设计，比现在凭空抽象靠谱。

候选：OKX（需要 passphrase，`credentials` 表已经是键值结构，能装下）、
Bybit、或者币安的币本位（同所不同产品线，抽象层次更浅）。

### 资讯的 AI 分析

**卡在"值不值得"上。** 按约定分两步：先跑资讯流几天，确认自己真会看，再花 AI 的钱和工。

已经算过的账：金十约 **2880 条/天**，全量分析每月约 \$55（deepseek-chat，价格自己复核）。
但其中绝大多数与持仓无关。**只分析「重要」+「命中持仓/自选」两类**，量掉到 30~60 条/天，
成本约 \$1/月 —— 差 50 倍。所以筛选不是优化，是这个功能能不能成立的前提。

防幻觉要靠结构不能靠 prompt：
- 所有数字由后端填（价格、涨跌、资金费率、你的持仓与浮盈都是自己的权威数据），
  模型只拿文本、只输出判断；
- 用 JSON 结构化输出，不解析自由文本；
- 模型报的币种过白名单，对不上的丢掉；
- 原文永远并排显示，AI 结论不取代原文。

## 明确不做

- **多用户 / 多租户**：见上。
- **下单执行**：只读边界是卖点，不是临时限制。
- **自研 K 线指标**：TradingView widget 够用；真要自研再换 klinecharts。
- **把资讯内容缓存后对外分发**：版权归各源站，自建实例自己看是另一回事。

## 踩过的坑（别再踩）

这些都在对应模块的注释里有详细版本，这里只留索引：

- **数据源验收要验正确性，不只是连通性** —— 曾经换到一个能推数据的 WS 端点，
  推的却是垃圾（KORUUSDT 标记价报 498.27，真实 22.91）。见 `config.py` 顶部。
- **分页用游标不用时间/偏移** —— 时间游标漏过同毫秒记录（实测漏 49/4623 笔，
  把净持仓算成 4147 而真实是 0）；资讯用 offset 翻页会因追加而错位。
- **`conn.executescript()` 会隐式提交**，迁移用它就不是原子的。见 `migrations.py`。
- **`hashlib.scrypt` 的 `maxmem` 必须显式传**，否则 n=2^15 直接报内存超限。
- **前 `text.upper()` 再匹配 ticker** 会把每个英文单词变成潜在标的
  （"rents rose" → ROSEUSDT）。见 `news/relevance.py`。
- **提前 return 不能站在 hook 前面** —— `ExchangeAccount` 曾因此让未配凭据的
  新用户打开持仓页直接白屏。`npm run smoke` 有回归用例。
- **`sslip.io` / `nip.io` 不在公共后缀列表**，所有子域名共用 Let's Encrypt 限额，
  签不出证书。`duckdns.org` 在列表里。
- **`sed -i` 不跟随符号链接**，会把 `sites-enabled` 里的链接换成普通文件，
  留下两份 server 块。
- **「保留旧值防抽风」和「剔除已下架」是两条不同的判据** —— 前者看本轮 REST
  有没有返回，后者看 exchangeInfo 还认不认。混成一条，要么榜单闪烁，要么留幽灵行。
  见 `hub._prune_delisted()`。
- **估算 WebSocket 带宽不能用单帧 gzip** —— `permessage-deflate` 默认开启且跨帧
  保留压缩字典，真实值要用同一个 `compressobj` 连续压多帧才量得准。
- **假实现要连静态常量一起给全** —— 冒烟里的 `WebSocket` mock 缺了 `OPEN`，
  于是 `ws.readyState === WebSocket.OPEN` 退化成 `undefined === undefined` 恒真，
  真崩溃反而被放过去了。
